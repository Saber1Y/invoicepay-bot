# InvoicePay

Invoice dApp on BOT Chain. Create proper invoices (client, work description, amount due, due date) with INV-### numbering. Share invoice link; pay in BOT or USDT. Verified Paid status with on-chain event.

- Testnet: Chain 968 (Bohr), CA: 0x27040EB63782F187C83F2959316099bD087f3E8f
- Mainnet: Chain 677 (BOT Chain)
- ERC-20 approval required for USDT before paying
